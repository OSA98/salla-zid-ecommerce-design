# نسخ Notion

كل ملف zip هنا يحتوي على المقال بصيغة Markdown ومجلد الصور الخاص به.

## طريقة الاستيراد

1. حمّل ملف الـ zip الخاص بالمقال.
2. افتح Notion، ثم اختر **Import** من القائمة الجانبية.
3. اختر **Text & Markdown**، ثم ارفع ملف الـ zip كما هو.
4. إذا لم تظهر الصور، فك ضغط الملف وارفع ملف الـ md مع مجلد images معًا.

الروابط بين المقالات في نسخ Notion تشير إلى صفحات المقالات على GitHub.
